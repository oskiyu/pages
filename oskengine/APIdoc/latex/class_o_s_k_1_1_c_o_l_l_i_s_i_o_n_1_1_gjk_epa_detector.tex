\doxysubsection{Descripción detallada}
Usa el algoritmo GJK para detección de colisiones, y el algoritmo EPA para obtener el MTV y un punto de contacto. 

Todos los {\ttfamily IBottom\+Level\+Collider} son también {\ttfamily \doxyref{IGjk\+Collider}{pág.}{class_o_s_k_1_1_c_o_l_l_i_s_i_o_n_1_1_i_gjk_collider}}, por lo que este detector es compatible con todos los colliders, independientemente de su tipo.

Por ello, es el detector que se usa por defecto.
