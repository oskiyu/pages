\chapter{Archivos de descripción de recursos. }
\label{jsonfiles}\index{Archivos de descripción de recursos.@{Archivos de descripción de recursos.}}
OSKengine usa numerosos archivos de descripción de recursos (con formato JSON), que añader metadatos a los archivos externos.

Existen varios de estos archivos de descripción de recursos\+:
\begin{DoxyItemize}
\item \doxyref{Archivo de descripción de material.}{pág.}{_material_file} Definen las propiedades de los materiales de renderizado.
\item \doxyref{Archivo de descripción de modelos 3D.}{pág.}{_model3_d_file} Define las propiedades de un modelo 3D.
\item \doxyref{Archivo de descripción de volumen de colisión 3D.}{pág.}{_pre_built_collider3_d_file} Define las propiedades de un volúmen de colisión 3D.
\item \doxyref{Archivo de descripción de una textura 2D.}{pág.}{_texture_file} Define las propiedades de una textura 2D.
\item \doxyref{Archivo de descripción de una fuente de texto.}{pág.}{_font_file} Define las propiedades de una fuente de texto.
\item \doxyref{Archivo de descripción de mapa cúbico.}{pág.}{_cubemap_file} Define las propiedades de un mapa cúbico.
\item \doxyref{Archivo de descripción de un mapa de irradiancia.}{pág.}{_irradiance_map_file} Define las propiedades de un mapa de irradiancia.
\item \doxyref{Archivo de descripción de un mapa de iluminación especular.}{pág.}{_specular_map_file} Define las propiedades de un mapa de iluminación especular.
