\doxysubsection{Descripción detallada}
Usa el algoritmo GJK para detección de colisiones, y después hace clipping sobre las caras de los colliders para obtener una serie de puntos de contacto. 

\begin{DoxyPrecond}{Precondición}
{\ttfamily first} es de tipo {\ttfamily Convex\+Collider}. 

{\ttfamily second} es de tipo {\ttfamily Convex\+Collider}.
