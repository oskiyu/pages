\doxysubsection{Descripción detallada}
Un sistema se encarga de ejecutar lógica. 

\begin{DoxyWarning}{Atención}
Para que una clase pueda ser usada como sistema, debe tener implementado OSK\+\_\+\+SYSTEM(class\+Name). Este debe ser un identificador único\+: no pueden haber dos tipos de sistemas con el mismo class\+Name. 
\end{DoxyWarning}
