\doxysubsection{Descripción detallada}
Un sistema consumidor es un sistema que se encarga de responder a eventos. Se recomienda no heredar directamente de esta clase, sino de la clase \doxyref{ITyped\+Consumer\+System}{pág.}{class_o_s_k_1_1_e_c_s_1_1_i_typed_consumer_system}, indicando el tipo de evento al que se reacciona.
